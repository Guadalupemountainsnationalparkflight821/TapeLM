## ❓ Frequently Asked Questions

**Does this software send my data to the internet?**
The program keeps your memory bank on your local hard drive. It does not upload your private information to servers.

**What is character-level processing?**
Traditional tools read whole words or groups of words. This software reads every single character. This detail allows for precise lookups and better control over how information is stored.

**How do I delete my data?**
Go to the settings menu and select clear memory. This action removes all stored entries from your local bank.

**Can I undo an edit?**
The software maintains a simple version history for each slot. You can revert to a previous version if you make a mistake during an update.
